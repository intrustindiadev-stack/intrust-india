Agentic architecture

One intelligence layer.
Zero parallel systems.

an action layer, not a rebuild

The agent sits between the user's conversation and the services InTrust already operates. It interprets the request, assembles permitted context, chooses from a fixed set of registered capabilities, and hands execution to the platform. Every result travels back through the same path in reverse — so the conversation never becomes a second source of truth.

What the layer adds

New
Intent understanding across text, image and voice.
Context assembly limited to the caller's permissions.
Capability selection from an explicit, reviewed registry.
Guardrails, rate limits and loop protection on every request.
Traceability: request, selection and outcome are all recorded.

What stays exactly as it is

Reused
Authentication — existing sessions and sign-in flows.
Permissions — the same ownership and access rules.
Business logic — pricing, availability, eligibility, fulfilment.
Data — one catalogue, one cart, one order record.
Audit — the platform's own logs remain authoritative.

No duplicate backend

The agent calls services, it does not recreate them.

Observable by default

Each hop can be inspected without changing the platform.

Reversible

Capabilities can be enabled or withdrawn independently.

Integration surface — proposed

The agent calls existing service endpoints, not raw tables.
Identity and permissions are resolved server-side from the session.
Read-only context is enabled first; write actions follow capability by capability.
No schema change is required to add the layer.

Behaviour when something fails

The user is told what could not be completed, in plain language.
No partial state is hidden — the conversation reflects reality.
Retries are bounded; the agent never loops indefinitely.
Every failure is logged with the capability that was attempted.
Design ruleIf a request cannot be served by a registered capability, the agent explains the limitation and routes the user to the normal journey. It never improvises a workaround.
