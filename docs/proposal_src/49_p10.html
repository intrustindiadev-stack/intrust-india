Governance rhythm we would propose
A capability register reviewed with InTrust before anything is enabled, plus a periodic review of agent activity and any user or merchant feedback that suggests a rule needs refining.
Observability we would propose
Every request records the intent, the capability selected, the permission outcome and the result — so behaviour can be examined without changing the platform underneath.
