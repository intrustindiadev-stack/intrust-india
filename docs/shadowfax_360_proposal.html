Technical Blueprint: Shadowfax Unified API & Push Webhook Sync

According to the official Shadowfax Unified Forward API Documentation (sfxunifiedapi.docs.apiary.io), the integration communicates via standard REST endpoints authenticated with an Authorization: Token <token_id> header.

Primary Unified API Endpoints

Operation Endpoint (Staging / Production Base: dale.shadowfax.in/api/) Role in Intrust Architecture
Pincode Serviceability GET /v1/clients/serviceability/?service=customer_delivery&pincodes=... Verifies delivery & seller pickup coverage before order placement.
Marketplace Order Creation POST /v3/clients/orders/ (Seller Pickup Model) Dispatches pickup from merchant outlet in Bhopal to customer.
Order Tracking (v4) GET /v4/clients/orders/{awb_number} Polls live shipment milestones (manifested, in-transit, OFD, delivered).
Order Cancellation POST /v2/clients/orders/cancel/ Cancels delivery request before rider pickup if customer cancels order.
Push Callback (Webhook) Intrust Endpoint: POST /api/webhooks/shadowfax Receives real-time push events from Shadowfax servers automatically.

Push Callback (Webhook) Payload & Supabase Synchronization

Shadowfax sends real-time HTTP POST notifications whenever an order changes status. The webhook payload maps directly into Intrust's existing database architecture:

// Incoming Shadowfax Push Callback Payload { "order_id": "ord_987654", // Intrust internal order ID "awb_number": "SFX1029384756", // Shadowfax Tracking AWB "status": "Out For Delivery", // Display status "event": "ofd", // Status enum: 'assigned_for_delivery', 'ofd', 'delivered' "rider_name": "Rahul Verma", // Delivery rider name (available on OFD) "rider_contact": "+919876543210", // Delivery rider phone "otp_verifed": "Y", // OTP proof of delivery validation "comments": "Out for delivery in MP Nagar" }
Zero Database Overhaul: When /api/webhooks/shadowfax receives this payload, it calls Intrust's existing Postgres function:
SELECT update_order_delivery_v3(p_order_id := 'ord_987654', p_delivery_status := 'out_for_delivery', p_tracking_number := 'SFX1029384756', p_notes := 'Rider: Rahul Verma (+919876543210)');
This updates the customer timeline and fires the automated WhatsApp notification with rider details immediately!
